共通の利用条件

本規約は、taketake-devが個人運営する動画制作・投稿ツールとJob Runnerに適用します。現在は本人が管理するアカウント・PC向けで、一般向けの会員登録や処理代行サービスは提供していません。

利用者は、自身が権限を持つアカウント・データ・素材を使い、各連携先の利用条件を守ってください。無断の認証情報利用、権利侵害、法令・サービス規約違反、APIの制限や安全措置の不正回避を禁止します。

データの取り扱いと削除は共通ポリシーとアプリ別ポリシーに従います。各アプリは独立した個人開発ツールで、Google、YouTube、Discord、Metaによる公式提供・推奨を示すものではありません。

Job Runnerの利用条件

実行するコマンド、外部送信先、ログ内容、認証範囲、PCの終了動作を事前に確認してください。ジョブの実行、通知、転送、Museによる確認の成功は保証しません。転送失敗時には古いログが残るため、日時とPC内ログを確認してください。外部サービス側の処理は各サービスの条件と設定に従います。

動画制作・投稿ツールの個別条件（継続適用）

以下の「本ツール」は動画制作・投稿ツールを指します。

1. 利用対象

本ツールは、運営者が管理する動画とYouTubeチャンネルのための個人運営ツールです。現在、一般向けの会員登録や投稿代行サービスは提供していません。

2. YouTubeとの関係

本ツールはYouTube API Servicesを使用します。本ツールを利用することで、利用者はYouTubeの利用規約にも拘束されることに同意するものとします。YouTubeの各ポリシーも遵守してください。

本ツールは独立して運営するものであり、GoogleまたはYouTubeによる公式提供・推奨を示すものではありません。

3. 投稿内容と権限

利用者は、自身が管理するチャンネルと、投稿する権利を持つ動画・音声・画像・文章を使用してください。素材や合成音声の利用条件、クレジット、著作権、プライバシーなどを確認する責任は利用者にあります。

投稿先、動画、タイトル、概要欄、タグ、公開範囲、子ども向け指定を確認してから投稿してください。定期実行を設定する場合も、使用する制作指示と投稿条件を事前に確認してください。

4. 禁止事項

  • 他人のアカウントや認証情報を無断で利用すること。
  • 著作権その他の権利を侵害する投稿。
  • 法令、YouTubeの利用規約・ポリシーに反する利用。
  • APIの制限や安全措置を不正に回避すること。

5. データと利用停止

情報の取り扱いはプライバシーポリシーに従います。Googleアカウントからアクセス権を解除して連携を停止できます。保存済みデータや投稿済み動画の削除方法も同ポリシーに記載しています。

6. 機能の変更・停止

本ツールは開発中です。機能の変更や停止、Google・YouTubeの仕様変更、認証期限、通信障害などにより、利用や投稿ができなくなる場合があります。継続的な利用、投稿の成功、YouTube上の処理時間や公開状態を保証するものではありません。

7. お問い合わせ・改定

本規約へのお問い合わせは、運営者のutsuroi.media@gmail.comへご連絡ください。本規約を変更する場合は、このページに掲載します。
