共通の取り扱い原則

運営者 taketake-dev が提供する個人開発アプリと、この案内サイトに適用します。各アプリの用途、要求権限、取得・送信データ、保存先・期間、外部サービス、削除方法は、下記のアプリ別ポリシーと合わせてご確認ください。アプリごとに異なる事項は、各アプリの説明に従います。

  • Google OAuthを使い、許可された連携の目的に必要な情報を扱います。アプリがGoogleアカウントのパスワードを受け取ることはありません。
  • OAuthクライアントと認証トークンはアプリごとに分けて管理します。サイトを共用しても、認証情報やアクセス権を共用するものではありません。
  • Googleユーザーデータを広告目的で販売しません。利用・外部送信は各アプリで説明した目的と、本人が許可した連携の範囲に限定します。
  • Googleの情報にはGoogleプライバシーポリシーも適用されます。

アプリ別プライバシーポリシー

  • 動画制作・投稿ツール：YouTubeへの投稿、PC内の保存とDPAPI保護
  • Job Runner：実行ログ、Drive転送、Muse・Discordとの連携

連携解除と削除

Googleアカウントの接続管理画面から各アプリのアクセス権を解除できます。解除だけではPC内や外部サービスに保存済みのデータは削除されません。各アプリの削除手順をご確認ください。

この案内サイト

GitHub Pagesで配信する静的サイトです。運営者が設置するアクセス解析、広告、入力フォーム、追跡用Cookieはありません。配信元の情報の取り扱いはGitHubのプライバシーに関する声明をご確認ください。

動画制作・投稿ツールの取り扱い（既存URLの継続掲載）

従来このURLを参照しているYouTube連携向けに、動画制作・投稿ツールの説明を引き続き掲載します。以下は同ツール固有の取り扱いです。Job Runnerには適用しません。

Google・YouTubeとの連携

本ツールはYouTube API Services（YouTube Data API）を使用します。GoogleのOAuth認証で、動画のアップロード権限（youtube.upload）とYouTube情報の読み取り権限（youtube.readonly）を要求します。現在、読み取り権限は投稿先チャンネルの照合に使用します。

Googleのサービスには、Googleプライバシーポリシーも適用されます。

利用する情報と目的

  • チャンネルID：認証したチャンネルと、指定された投稿先が一致することを確認します。
  • 動画と投稿情報：指定されたMP4、タイトル、概要欄、タグ、カテゴリ、公開範囲、子ども向け指定をYouTubeへ送信します。
  • 認証トークン：許可されたAPIの利用と、再認証なしで継続して投稿するために使用します。
  • 投稿結果と処理記録：動画ID、URL、応答に含まれる処理状態、日時、エラー識別情報などを、成否の確認、障害調査、重複投稿の防止に使用します。

本ツールがGoogleアカウントのパスワードを取得・保存することはありません。

保存と保護

動画、投稿情報、投稿結果などは本ツールを実行するPCへ保存します。認証トークンと再開可能アップロードのセッション情報は、Windowsのユーザー単位の暗号化機能（DPAPI）で保護し、通常の制作成果物とは別の認証保存先に保存します。これらの秘密情報を公開サイトや制作成果物へコピーする設計にはしていません。

生成物の保存期間は実行環境の設定と削除処理によります。標準の削除設定はMP4が7日、実行データが30日ですが、設定変更や削除処理の未実行によって実際の保存期間は異なります。認証・アップロードセッションの保存データは、この削除処理の対象外です。不要になった認証データは運営者が別途削除します。

外部への送信と公開

認証と投稿に必要な情報をGoogle・YouTubeへ送信します。アップロードした動画や投稿情報の公開範囲は、指定された投稿条件とYouTube側の設定に従います。

本ツールのYouTube連携処理では、取得したGoogle・YouTubeの情報を広告目的で販売したり、AIモデルの学習へ送信したりしません。運営者によるデータの利用は、本ポリシーに記載した目的に限定します。

アクセス権の解除とデータの削除

Googleアカウントの接続管理画面から、本ツールのアクセス権を解除できます。解除後は、その認証を使用したAPI利用ができなくなります。

アクセス権の解除だけでは、PCに保存済みのファイルやYouTubeに投稿済みの動画は自動削除されません。ローカルの認証・投稿記録の削除は運営者へご連絡ください。運営者自身が利用する場合は、関連処理を停止したうえで、設定した保存先から対象データを削除します。投稿済み動画はYouTube Studioなど、YouTubeの管理機能で削除できます。
